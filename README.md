# 🎮 Tic-Tac-Toe Game in Python

A simple and interactive Tic-Tac-Toe game developed using Python. This project lets two players play the classic X and O game on a 3×3 board.

## 📌 Project Overview

Tic-Tac-Toe is a classic two-player game where players take turns marking spaces on a 3×3 grid. The first player to align three symbols horizontally, vertically, or diagonally wins the game.

## ✨ Features

- 🎮 Simple and interactive gameplay
- ❌ Player X and ⭕ Player O
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🔄 Easy-to-understand game logic
- 🐍 Developed using Python

## 🎯 How to Play

1. Run the Python program.
2. Players take turns choosing positions on the board.
3. Player X and Player O alternate their moves.
4. The first player to get three matching symbols in a row wins.
5. If all spaces are filled without a winner, the game ends in a draw.
